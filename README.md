# Digital Logic Hub

A personal repository for digital logic circuits, hardware design, and experiments.

##  Contents
* **Combinational Circuits:** Logic gates, Half Adder, Full Adder, Decoders, Mux.
* **Sequential Circuits:** Flip-Flops (SR, D, JK, T), Counters, Registers.
* **Projects & Simulations:** Circuit diagrams and helper scripts.
